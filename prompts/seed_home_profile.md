# HA Instance Home Profile

This document is regenerated at every RAG refresh and describes the current
Home Assistant installation. Use it to understand what integrations and
components are present when diagnosing issues or proposing automations.

The profile includes: HA Core, OS, and Supervisor versions; the list of
installed integrations (by domain); custom HACS components; and the top-level
keys present in configuration.yaml.

When an agent calls `query_knowledge` about an integration or automation
pattern, this profile chunk provides the installation context so advice can be
tailored to what is actually installed.
